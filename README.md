# CISI Information Retrieval

Поисковая система на классическом датасете CISI, реализованная с нуля на Python.

## О датасете

CISI — коллекция из 1460 научных статей по библиотечному делу и информатике.

| Файл | Содержит |
|------|----------|
| `CISI.ALL` | 1460 документов (заголовок, автор, абстракт, ссылки) |
| `CISI.QRY` | 112 поисковых запросов |
| `CISI.REL` | Эталонная разметка (какие документы релевантны запросу) |

Разметка есть для 76 из 112 запросов. Запросы без разметки исключаются из оценки.
Первые два из четырёх столбцов `CISI.REL` задают пару запрос/документ; нули
в остальных столбцах не означают нерелевантность.

## Реализовано

- **Предобработка текста:** токенизация, удаление стоп-слов, стемминг (Porter), лемматизация (WordNet)
- **Инвертированный индекс:** простой (слово → список ID) и обогащённый (TF, DF, IDF, длина документа)
- **Отдельные индексы** по заголовкам, авторам, тексту
- **Алгоритмы ранжирования:**
  - Булев поиск (AND/OR)
  - TF-IDF с нормализацией по длине документа
  - BM25 с настраиваемыми параметрами (k1, b)
- **Fallback:** если в выбранной секции ничего не найдено — поиск по общему индексу с пониженным скором
- **Метрики качества:** Precision@K, Recall@K, AP и MAP по всем 76 размеченным запросам

## Основные выводы

| Компонент | Лучший выбор | Почему |
|-----------|:---:|-------|
| Препроцессинг | Стемминг | Наибольший MAP среди проверенных вариантов |
| Алгоритм | BM25 | P@1 = 0,5263 против 0,3684 у TF-IDF на общем стеммированном индексе |
| Поле для поиска | Общий индекс | Объединяет заголовки, авторов и текст |

Для этой конфигурации BM25: P@5 = 0,4263, P@10 = 0,3697, MAP = 0,2281.
Это сравнение фиксированных конфигураций на CISI, а не доказательство
универсального превосходства BM25 или оптимальности параметров.
Полные результаты и ограничения проверки: [отчёт](docs/AUDIT.md), [метрики](results/metrics.csv).

Поиск по полям использует весь запрос с соответствующей обработкой.
Fallback включается явно; в сравнении полей он отключён.
TF-IDF реализован как взвешенная сумма с делением на длину документа,
а не как косинусная близость. В BM25 используется положительный сглаженный
IDF, как в [Apache Lucene](https://lucene.apache.org/core/9_12_1/core/org/apache/lucene/search/similarities/BM25Similarity.html).

## Запуск

```bash
git clone https://github.com/AlexKorn2531/Information_retrieval-IR-.git
cd Information_retrieval-IR-
python -m pip install -r requirements.txt
python -m jupyter notebook notebook/information_retrieval.ipynb
```

Требуется Python 3.11 или новее. При первом запуске ноутбук проверит ресурсы
NLTK (`punkt_tab`, `stopwords`, `wordnet`) и попробует скачать отсутствующие.
WordNet обязателен: сравнение лемматизации без него прекращается с ошибкой.
При необходимости ресурсы можно установить заранее:

```bash
python -m nltk.downloader punkt_tab stopwords wordnet
python -m unittest discover -s tests -v
python scripts/export_results.py
```

Основной ноутбук и `information_retrieval copy.ipynb` содержат одинаковый код.
Запуск поддерживается из корня репозитория и из каталога `notebook`.
