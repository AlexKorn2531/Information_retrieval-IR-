# Проверка проекта

Дата проверки: 8 октября 2026 года.

## Область проверки

Проверены оба ноутбука, README, зависимости, все три файла CISI,
три версии теоретической работы (`my_research_work`, `my_research_work_def`,
`Research_work`), практический отчёт `Technical_specifications`, презентация
и текст выступления. План и задание рассмотрены как требования.
`IR.pdf` — справочный учебник, а не авторский результат проекта:
проверены доступность текста и разделы, связанные с формулами и оценкой;
полная редакторская проверка всего учебника не выполнялась.

## Исправленные проблемы

1. Исправлены пути к данным и обработка неизвестных секций парсером;
   повторяющиеся ID и ссылки на отсутствующие запросы/документы вызывают ошибку.
2. WordNet обязателен. Подмена лемматизации сохранением исходных токенов удалена;
   учитывается установленный архив `wordnet.zip`.
3. Исправлен подсчёт сырого словаря у записей без авторов.
   Размер словаря отделён от числа вхождений токенов.
4. При поиске в заголовках и авторах документов используется весь текст запроса.
   Раньше отсутствие соответствующего поля у запроса давало ложные нули.
5. BM25 переведён на положительный сглаженный IDF, используемый Apache Lucene.
   Ранее был выбран IDF `ln(N/df)`: такая вариация встречается, но не совпадала
   с приведённой в отчёте вероятностной формулой. Теперь код и пояснения согласованы.
6. Исправлены пустые выдачи, fallback с подходящей предобработкой,
   стабильная сортировка при равных оценках и проверка параметров BM25.
7. Precision@K и Recall@K используют всё множество релевантных документов.
   Добавлены AP, MAP и средние по всем размеченным запросам.
8. Добавлено сравнение с сохранением стоп-слов и оценка булевых AND/OR как множеств.
9. Время индексации включает весь вызов, включая сортировку и расчёт метаданных.
10. Исправлены неверный пример Porter, устаревшие числа и обобщения по пяти запросам.
    Нумерация текста выступления согласована с 18 слайдами.
11. Уточнены ограничения лемматизации, векторного поиска, сжатия и RAG.
    RAG не гарантирует отсутствие галлюцинаций; GPU не обязателен для каждого
    случая семантического поиска; выигрыш от сжатия требует измерений.
12. В двух титульных заголовках восстановлены отдельные строки и сохранено
    полное название вуза из исходного шаблона. Большие листинги разбиты на
    отдельные абзацы с моноширинным шрифтом. В пяти авторских DOCX включено
    обновление полей при открытии, чтобы оглавление могло пересчитать страницы.
    В практическом отчёте исправлено обозначение группы и уточнено, что BM25
    контролирует влияние длины, а выбор стемминга основан на измеренном MAP.

## Данные и результаты

В локальной коллекции 1460 документов и 112 запросов.
Разметка присутствует для 76 запросов; остальные 36 исключены из оценки,
а не объявлены запросами без релевантных документов.
Дубликаты связей релевантности не увеличивают знаменатели метрик.

Средние по 76 запросам для общего стеммированного индекса:

| Модель | P@1 | P@5 | P@10 | MAP |
|---|---:|---:|---:|---:|
| TF-IDF с делением на длину | 0,3684 | 0,3526 | 0,3118 | 0,1995 |
| BM25, k1=1,2, b=0,75 | 0,5263 | 0,4263 | 0,3697 | 0,2281 |

P@1 BM25 выше примерно в 1,43 раза. Старое отношение 3 было получено
на пяти запросах и не характеризует полную размеченную выборку.
По MAP наиболее успешен общий стеммированный индекс, но лучшая
конфигурация может зависеть от выбранной метрики.
У OR-поиска средний Recall = 0,9601, а не гарантированные 100%.

Словарь документов: 12610 сырых токенов, 10748 после очистки,
6936 после Porter и 9582 после WordNet. Словарь запросов:
2077, 1836, 1263 и 1635 соответственно.
Porter: `library → librari`, `libraries → librari`,
`librarianship → librarianship`.

## Проверки

12 тестов проверяют независимые расчёты TF-IDF/BM25 на небольшом корпусе,
метрики, целостность данных, настоящий WordNet, поиск по полям,
fallback, пустые индексы, параметры, парсер, порядок результатов
и структуру и синтаксис рабочего ноутбука.

```bash
python -m nltk.downloader punkt_tab stopwords wordnet
python -m unittest discover -s tests -v
python scripts/export_results.py
```

До удаления дубликата оба ноутбука были проверены через настоящий Jupyter kernel.
Основной проверен из корня и каталога `notebook`, копия — из `notebook`.
CSV получены выполнением исправленного кода с настоящим WordNet.
Версии среды проверки: Python 3.13.14, NLTK 3.9.4, pandas 3.0.2.
Версии, настройки и контрольные суммы данных сохраняются в `results/metadata.json`.

Добавлены четыре структурных теста DOCX: целостность архивов и XML,
обновление полей, разбиение титульных заголовков и отсутствие огромных
абзацев кода. Все четыре прошли после последних изменений. Сравнение с
предыдущим коммитом подтвердило неизменность встроенных изображений и OMML-формул.

При повторной проверке всех 16 тестов 15 прошли, а тест парсера остановился
на `PermissionError` при записи в временную папку Windows. Повторный запуск
вне песочницы не получил разрешения; это ограничение текущей проверки,
а не подтверждённая ошибка парсера. В предыдущем полном запуске все
12 тестов поисковой логики прошли.

## Ограничения

Это сравнение фиксированных конфигураций на одной коллекции, без отдельной
валидации гиперпараметров и проверки статистической значимости.
WordNetLemmatizer использует существительные по умолчанию, без POS-разметки.
TF-IDF здесь — сумма весов с нормализацией по длине, не косинусная модель.
Повторения термов запроса учитываются линейно.
Измерения времени одиночные и зависят от оборудования и нагрузки.
Второй столбец `.X` не трактуется как подтверждённое число цитирований.

Не заполнены подписи, оценки, даты утверждения и прочие административные
поля университетских шаблонов: эти сведения нельзя получить из расчётов.
Проверка не подтверждает полноту цитирования всех иллюстраций или соответствие
формальным требованиям кафедры, которых в проекте нет.

Исходные `my_research_work.pdf` и `my_research_work_def.pdf` остаются старыми
снимками и содержат прежние формулировки. Автоматическое сохранение PDF в Word
зависает даже для простого временного документа. Дополнительная проверка
Word без надстроек не устранила зависание; альтернативный экспорт и загрузка
конвертера не получили разрешения. Эти PDF не публикуются вместе с исправлениями.
Для актуального текста используются исправленные DOCX и этот отчёт.
Первый DOCX был открыт Word; архивы и XML остальных документов проверены.
Все 18 слайдов отрисованы в PowerPoint и визуально просмотрены;
высоты столбцов диаграммы обновлены вместе с числовыми подписями.
Полная визуальная проверка каждой страницы DOCX не завершена.

## Очистка проекта

После проверки удалены временные скрипты аудита, извлечённые тексты,
контрольные рендеры, временные библиотеки и ресурсы NLTK, кеш Python и
контрольная копия Jupyter. Освобождено около 169 МиБ.
Полностью идентичный `information_retrieval copy.ipynb` удалён; рабочим
остаётся `notebook/information_retrieval.ipynb`. Проверка дубликата заменена
проверкой структуры и синтаксиса рабочего ноутбука.

Все документы пользователя, включая справочные материалы и старые PDF,
сохранены на прежних местах. Данные CISI, результаты и тесты сохранены.
Временные библиотеки и ресурсы для запуска не включаются в репозиторий:
зависимости устанавливаются из `requirements.txt`, ресурсы NLTK — согласно README.
